Entry for the [make.fun](https://make.fun) competition
["The Dog Ate My Homework: Funniest Excuse"](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

`main.py` writes one line to `/output/entry.txt`: the excuse a dog gives
after being caught eating the homework, in the dog's own voice.

> You said sit, stay, leave it. I did two out of three, and that's the best grade I've ever gotten.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
